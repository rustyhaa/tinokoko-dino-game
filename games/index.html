티노코코 놀이터

3살 쌍둥이와 아빠가 몇 분씩 노는 게임 모음. 실패·시간제한·점수 없이, 손가락 하나로 놉니다.

잘 시간
시간이 되면 어느 게임에서든 티노·코코가 하품하고 잠들어요. 깨우려면 게임 화면 오른쪽 아래 해 버튼을 1초 꾹.
  • 까꿍 숨바꼭질물건을 톡! 숨은 티노·코코 찾기

    노는 법 물건을 톡 누르면 뒤에서 친구가 "까꿍!" 나와요. 티노와 코코를 둘 다 찾으면 다음 장면(바닷가→숲→밤).

    익히는 것 안 보여도 그 자리에 있다는 감각, 손가락 탭.

    같이 놀 때 "티노 어디 숨었지?" 하고 물어봐 주세요. 한참 못 찾으면 별이 숨은 곳을 알려줘요.

  • 무지개 방울방울을 터뜨려 무지개 채우기

    노는 법 방울을 톡(또는 쓱) 터뜨리면 같은 색 무지개 줄이 켜져요. 일곱 색이 다 켜지면 축하하고 배경이 바뀌어요.

    익히는 것 색 구분, 탭과 문지르기.

    같이 놀 때 오른쪽 위 톱니에서 '색 이름'을 고르면 색 이름을 말해줘요. 둘이 동시에 터뜨리면 하이파이브.

  • 목욕탕쓱쓱 문질러 깨끗하게

    노는 법 티노·코코 몸의 얼룩을 손가락으로 쓱쓱 문지르면 거품이 나며 지워져요. 깨끗해지면 샤워하고 다음엔 물감·나뭇잎·모래가 묻어 와요.

    익히는 것 문지르기(끌기), 씻기 습관.

    같이 놀 때 실제 목욕 전에 한 판 하면 "우리도 씻자"로 이어가기 좋아요. 오리를 누르면 꽥.

  • 배 태우기친구들을 끌어 배에 태우기

    노는 법 모래밭 친구를 끌어 배 쪽으로 가져가면 자석처럼 쏙 앉아요. 넷이 타면 뱃고동 뿌우, 출항!

    익히는 것 끌어다 놓기.

    같이 놀 때 두 아이가 각자 한 친구씩 동시에 끌 수 있어요.

  • 그림자 짝꿍같은 모양 그림자에 쏙

    노는 법 아래 쟁반의 모양을 끌어 위쪽 같은 그림자에 가져가면 딱 붙고 "사과!"처럼 이름을 말해요. 넷 다 채우면 그림이 움직여요.

    익히는 것 모양 구분, 사물 이름.

    같이 놀 때 붙은 그림을 다시 누르면 이름을 또 말해줘요. 따라 말해 보기.

  • 별자리 잇기반짝이는 별을 차례로 톡

    노는 법 크게 반짝이는 별을 톡(또는 쓸고 지나가기) 하면 선이 이어지고 음이 하나씩 올라가요. 다 이으면 고래·공룡 별자리가 빛나요.

    익히는 것 순서 따라가기, 집중.

    같이 놀 때 잠자기 전 차분한 놀이로 좋아요. 잘 시간과 함께 쓰기.

  • 꼬마 정원톡톡 비 내려 쑥쑥 키우기

    노는 법 흙더미를 톡 누르거나 문지르면 구름에서 비가 내려 새싹→꽃·열매로 자라요. 넷 다 자라면 바구니로 수확.

    익히는 것 원인과 결과, 채소·꽃 이름.

    같이 놀 때 다 자란 걸 누르면 이름을 말해요. "당근은 무슨 색?" 물어보기.

  • 쿵짝 악단두드리면 둘이 춤춰요

    노는 법 북·실로폰·나팔·탬버린을 두드리면 티노·코코가 춤춰요. 실로폰은 쓸면 또로롱. 12번마다 친구가 와서, 셋이 모이면 피날레.

    익히는 것 박자, 소리 탐색. 아무렇게나 쳐도 어울리는 음만 나와요.

    같이 놀 때 아빠가 손뼉으로 박자를 맞춰 주세요.

  • 비눗방울 후꾹 누르면 방울이 커져요

    노는 법 화면을 꾹 누르고 있으면 방울이 커지고, 떼면 날아가요. 크게 키우면 친구가 타요. 날아가는 방울을 톡 치면 퐁!

    익히는 것 길게 누르기, 기다리기.

    같이 놀 때 여러 손가락으로 동시에 불 수 있어요.

  • R동시점프 러너기존 달리기 게임 · 집 버튼 있음

    노는 법 달리다가 탭으로 점프해 돌멩이를 넘어요. 돌에 부딪히면 끝나고 점수가 있어요.

    참고 실패와 점수가 있는 예전 게임이라 별 시범·잘 시간은 없어요. 왼쪽 위 집 버튼으로 나갈 수 있어요.

폰·태블릿에 앱으로 설치하기
  • 아이폰·아이패드: Safari로 이 화면 열기 → 공유 버튼 → "홈 화면에 추가"
  • 안드로이드: Chrome으로 열기 → 오른쪽 위 ⋮ → "앱 설치" 또는 "홈 화면에 추가"
  • 아이콘은 "티노코코 놀이터" 하나만 생겨요. 한 번 열어 두면 인터넷 없이도 모든 게임이 열려요.
  • 게임 중 왼쪽 위 집 버튼을 톡 누르면 여기로 돌아와요.
