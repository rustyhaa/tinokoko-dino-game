부모 화면

부모 설정

아이 이름

넣으면 이름 방울·글자 까꿍 등에 이름 글자로 나와요. 이 기기에만 저장돼요.

좋아하는 것

켜 두면 공룡 23종(티라노사우루스·트리케라톱스 등)과 고래 23종(혹등고래·범고래 등)이 모든 게임에 더 자주 나와요. 별자리엔 고래·공룡 별자리, 정원엔 공룡알, 목욕탕엔 장난감 고래, 실로폰엔 공룡·고래 친구가 와요.

단계

이번 주 글자

최대 3개. 고른 자음과 그 자음으로 시작하는 단어가 여러 게임에 더 자주 나와요.

책상 놀이(글자 그리기)
켜면 지도 오른쪽 아래 책상이 열려요. 책상을 톡 하면 '글자 별자리'(별을 이어 자음 그리기)로 가요. 끄면 흐리게 보이고 눌러도 들어가지 않아요.
아빠·엄마 목소리로 읽어주기

녹음해 둔 글자는 기기 음성 대신 그 목소리로 읽어줘요. 녹음은 이 기기에만 저장되고 밖으로 보내지 않아요.

이번 주 리포트
오늘 본 글자
생일 생일 날엔 게임 화면 위에 이름 글자 깃발과 케이크가 나오고 "생일 축하해" 하고 말해줘요 (연도는 상관없어요).
계절 장식
겨울엔 눈, 봄엔 꽃잎, 가을엔 낙엽이 천천히 내려요.
배경음악
별자리·발자국 길·짝꿍·까꿍에서 아주 작게 흘러요. 글자를 읽을 땐 더 작아져요. 실로폰은 아이가 연주하니 음악 없음.
불어서 방울
'내 이름 방울'에서 마이크에 "후~" 불면 방울이 생겨요. 켜면 처음 한 번 마이크 허락을 물어요. 소리 크기만 보고 녹음·저장하지 않아요.
잘 시간
폰·태블릿에 앱으로 설치하기
  • 아이폰·아이패드: Safari로 이 화면 열기 → 공유 버튼 → "홈 화면에 추가"
  • 안드로이드: Chrome으로 열기 → 오른쪽 위 ⋮ → "앱 설치" 또는 "홈 화면에 추가"
  • 아이콘은 "한글 놀이터" 하나만 생겨요. 한 번 열어 두면 인터넷 없이도 모든 게임이 열려요.
  • 게임 중 왼쪽 위 집 버튼을 톡 누르면 지도로 돌아와요. 이 부모 화면은 지도 왼쪽 위 톱니를 1초 꾹 누르면 열려요.
  • 아이가 다른 앱으로 못 나가게 하려면: 아이폰 설정 → 손쉬운 사용 → 사용법 유도 접근 / 안드로이드 설정 → 보안 → 앱 고정.

지도 속 놀이

  • 공룡·고래 만나기숨은 친구를 톡! 이름을 읽어 줘요

    노는 법 지도의 숲(공룡)·바다(고래)에서 열려요. 덤불·바위 뒤에 친구가 숨어 살짝 보여요. 물건을 톡 하면 친구가 가운데로 까꿍 나와 "트, 리, 케…" 이름을 글자마다 읽어 줘요(읽는 글자가 커져요). 다 만나면 새 친구들, 두 판마다 숲과 바다가 바뀌어요.

    익히는 것 긴 이름을 글자마다 끊어 듣기, 공룡·고래 종류. '글자 까꿍'과 '그림책'을 합친 놀이예요.

    같이 놀 때 나온 친구를 다시 톡 하면 또 읽어 줘요. 이름표를 손가락으로 짚으며 따라 읽어 주세요.

  • 글자 목욕쓱쓱 닦으면 단어가 나와요

    노는 법 벽 타일의 얼룩을 손가락으로 쓱쓱 문지르면 그림과 단어가 드러나며 읽어줘요. 두 장 다 닦으면 샤워.

    익히는 것 통단어, 문지르기(끌기).

    같이 놀 때 깨끗해진 타일을 누르면 다시 읽어줘요.

  • 글자 달리기폴짝! 풍선 글자를 모아 단어를

    노는 법 티노와 코코가 달려요. 화면 왼쪽을 톡 하면 티노, 오른쪽을 톡 하면 코코가 폴짝 뛰어 글자 풍선을 터뜨려요. 글자가 다 모이면 "나, 비. 나비!" 하고 단어를 읽고, 그림 깃발이 길가에 꽂혀요. 단어 셋이면 결승선!

    익히는 것 글자 하나하나 → 단어로 잇기.

    같이 놀 때 두 아이가 왼쪽·오른쪽을 하나씩 맡아 보세요. 놓친 풍선은 다시 오고, 돌멩이에 부딪혀도 괜찮아요.

  • 글자 정원쑥쑥 자라면 이름표가 피어요

    노는 법 흙을 톡 누르거나 문지르면 비가 내려 자라고, 다 자라면 "당근" 이름표가 피어나요. 바구니에 단어 카드가 모여요.

    익히는 것 채소·꽃 이름, 원인과 결과.

  • 가나다 실로폰두드리면 글자가 노래해요

    노는 법 실로폰 바마다 글자가 있어 치면 그 글자를 소리 내요. 쓸면 차례로. 북·나팔·탬버린도 있고, 친구가 이름표를 달고 와요.

    익히는 것 글자 소리, 순서.

    같이 놀 때 "가, 나, 다" 같이 불러 주세요.

  • 글자 별자리별을 이으면 자음이 빛나요

    노는 법 크게 반짝이는 별을 차례로 톡 하면 선이 이어져 자음이 완성돼요. 별은 쓰는 순서(획순)대로 놓여 있어요. 두 판에 한 번은 '긋기' 판: 반짝이 별을 손가락으로 따라 쓱 그으면 빛 길이 남아요(삐뚤어도 괜찮아요).

    익히는 것 자음 모양, 쓰기 순서 감각, 손가락으로 따라 쓰기.

    같이 놀 때 잠자기 전 차분한 놀이로 좋아요.

+다른 놀이 5개카드 열기
  • 글자 까꿍물건을 톡! 그림과 이름이 까꿍

    노는 법 물건을 톡 누르면 뒤에서 그림이 나오고 "까꿍! 나, 비. 나비!" 하고 읽어줘요. 티노·코코를 둘 다 찾으면 다음 장면.

    익히는 것 그림·소리·글자 잇기(통단어), 이름 글자.

    같이 놀 때 글자를 손가락으로 가리키며 따라 읽어 주세요.

  • 공룡·고래 그림책넘기면 친구 이름을 읽어 줘요

    노는 법 양옆 화살표를 톡(또는 옆으로 쓱) 하면 다음 친구가 나와요. 공룡 23종은 숲, 고래 23종은 바다에서. 친구를 톡 하면 콩 뛰며 "티, 라, 노…" 이름을 읽어 줘요.

    익히는 것 긴 이름을 글자마다 끊어 듣기, 공룡·고래 종류.

    같이 놀 때 그림책처럼 한 장씩 넘기며 생김새를 이야기해 주세요. 설정의 좋아하는 것에서 고래를 켜면 고래가 먼저 나와요.

  • 자음 짝꿍ㄱ·ㄴ·ㅁ·ㅇ 같은 모양에 쏙

    노는 법 아래 자음 블록을 위쪽 같은 모양 그림자에 끌어 놓으면 딱 붙고 "기역! 고래의 기역" 하고 읽어줘요. 1단계에선 그림을 그림자에 맞춰요.

    익히는 것 자음 모양 구분, 첫소리.

    같이 놀 때 붙은 블록을 다시 누르면 또 읽어줘요. 책·간판에서 같은 모양 찾기로 이어가기.

  • 공룡 발자국 길발자국을 톡! 쿵쿵 글자 길

    노는 법 반짝이는 발자국을 톡 하면 티노와 코코가 번갈아 훌쩍 뛰어 그 글자를 읽어요. 끝까지 가면 고래가 물을 뿜으며 "공, 룡. 공룡!" 하고 단어를 완성해요. 두 아이가 한 번씩 번갈아 누르기 좋아요.

    익히는 것 음절 하나하나 → 단어로 잇기, 왼쪽에서 오른쪽으로 읽는 방향.

    같이 놀 때 발자국을 하나씩 짚으며 같이 소리 내 주세요. 다 간 뒤 발자국을 누르면 그 글자를 다시 읽어요.

  • 첫소리 배친구를 배에 태우면 첫소리를 들려줘요

    노는 법 친구를 톡 하거나 끌어 오면 배에 앉고 "기역. 고래."처럼 첫소리와 이름을 읽어줘요. 넷이 다 타면 출발.

    익히는 것 첫소리, 동물·물건 이름.

    같이 놀 때 두 아이가 한 친구씩 동시에 태울 수 있어요.

+예전 게임 3개카드 열기
  • 내 이름 방울방울 속 글자로 이름을 만들어요

    노는 법 화면을 누르면 방울이 생겨요(꾹 누르면 크게). 방울마다 이름 글자가 하나씩 들어 있어 톡 터뜨리면 아래 이름 칸에 쏙. 다 모이면 이름을 읽어줘요.

    익히는 것 아이 이름·가족 이름 글자. 아래 '아이 이름'에 넣으면 그 이름부터 나와요.

    불어서 방울 아래 설정에서 켜면 마이크에 "후~" 불어서도 방울이 생겨요.

  • 가나다 방울방울 속 글자를 톡

    노는 법 방울마다 글자가 들어 있어 톡 터뜨리면 그 소리를 내요. 일곱 개가 다 모이면 무지개 완성. 3단계는 가나다라마바사.

    익히는 것 글자 하나하나의 소리.

    같이 놀 때 오른쪽 위 톱니에서 '동요'·'색 이름'으로도 바꿀 수 있어요.

  • R예전 동시점프 러너예전 달리기 게임 (점수 있음)

    노는 법 달리다가 탭으로 점프해 돌멩이를 넘어요. 실패와 점수가 있는 예전 게임이라 한글·별 시범·잘 시간은 없어요.
