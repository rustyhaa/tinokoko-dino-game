# 3D 품질 개선 방안 (three.js)

작성: 2026-11-07 · 비교 이미지: `quality_before_after.png` · 개선판 코드: `proto/band2.html`

## 결론
- 첫 예시가 "20년 전" 같아 보인 이유는 **세 가지**: ① 조명이 단순(빛 하나 + 균일한 하늘빛), ② 재질이 단색 플라스틱, ③ 후처리 없음 — 그리고 가장 큰 이유 ④ **3D 모델 자체가 단순한 도형 + 캐릭터는 납작한 그림판**.
- ①②③은 코드로 바로 고칠 수 있고, 실로폰에 적용해 봤다(전후 비교 이미지). 뚜렷이 나아지지만, **"요즘 게임" 느낌의 대부분은 ④ 모델·캐릭터 품질**에서 온다.
- 추천 방향: **장난감 미니어처(디오라마) 화풍** + **AI로 만든 3D 모델(티노·코코 포함)** + 이번에 넣은 조명·후처리 묶음. 실로폰 한 판으로 먼저 실기기 확인.

## 1. 코드로 바로 되는 것 (실로폰에 적용함)
| 항목 | 한 일 | 효과 |
|---|---|---|
| 환경광 | 방 반사광(RoomEnvironment)을 만들어 모든 재질에 은은한 반사 | 장난감처럼 반짝이는 표면 |
| 조명 | 따뜻한 무대 핀 조명(부드러운 그림자) + 차가운 뒤쪽 윤곽광 + 분홍 보조광 | 입체감, 무대 분위기 |
| 재질 | 건반 유광 코팅(clearcoat), 채 머리 펠트(sheen), 금속 핀, 나무결 바닥 | 물건마다 다른 질감 |
| 모양 | 모서리 둥근 상자(RoundedBox) | 장난감 같은 부드러움 |
| 후처리 | 틈새 그늘(GTAO), 반짝이 빛 번짐(Bloom), 미니어처 초점(Bokeh), 영화식 색 처리(ACES), 계단 현상 제거(SMAA) | "렌더링된 게임" 느낌 |

주의: 후처리는 무겁다. 오래된 태블릿에선 틈새 그늘·초점 효과를 끄는 '가벼운 모드'가 필요할 수 있음 (실기기 확인 전).

## 2. 품질 차이의 대부분: 3D 모델·캐릭터
| 방법 | 내용 | 장단점 |
|---|---|---|
| **AI 3D 생성 (추천)** | 손그림 티노·코코·소품 그림을 넣으면 3D 모델(GLB)로 만들어 주는 서비스. Meshy·Tripo 는 자동 리깅(뼈대)과 기본 동작까지 제공한다고 알려짐 | 빠르고 화풍이 그림과 이어짐 / 유료 요금제·이용 조건 확인 필요, 얼굴 디테일은 손볼 수 있음 |
| 무료 공개 3D 소품 묶음 | 저작권 걱정 없는(CC0) 장난감풍 소품 묶음 | 소품은 충분 / 티노·코코는 없음 |
| 직접 제작·의뢰 | 블렌더로 모델링하거나 3D 아티스트 의뢰 | 품질 최고 / 시간·비용 |

티노·코코가 3D 캐릭터가 되면: 건반을 칠 때 몸을 흔들고, 점프하고, 고개를 돌리는 실제 동작이 가능 (지금은 그림판이 기울어질 뿐).

## 3. 움직임 다듬기 (코드)
- 눌림·튕김(스쿼시·스트레치), 부드러운 감속 곡선, 카메라가 살짝 따라오는 움직임
- 건반을 치면 빛 고리·음표 입자·글자 카드가 튀어오름 (지금은 정지 화면)

## 4. 진행 순서 (제안)
1. 화풍 결정: 장난감 미니어처(유광·둥근·따뜻한 조명) — 이번 개선판 방향
2. 티노·코코 3D 모델: 그림 1장씩을 AI 3D 생성 서비스에 넣어 GLB 받기 (그림 만들 때처럼 사용자가 만들어 `art/3d/`에 올리면 Claude가 연결)
3. 실로폰 3D 판 `band3d/` 를 기존 실로폰과 나란히 → 실기기에서 프레임·발열 확인
4. 좋으면 공룡 발자국 길·글자 정원 순서로

## 확인 못 한 것
- 예시는 서버의 소프트웨어 그래픽으로 렌더링했다 → 실제 기기 GPU 에선 더 깨끗하고 빠를 수 있지만, 속도·발열은 실기기에서만 알 수 있음
- AI 3D 서비스의 요금·상업 이용 조건·만화 캐릭터 결과 품질은 블로그 비교 글로만 확인

## 5. 코드만으로 한 개선 — 글자 정원 개선판 (2026-11-07)
예시: `garden_v2.png` (위 전체 모습, 아래 왼쪽 첫 예시 / 오른쪽 게임 시점), 코드: `proto/garden2.html`
- **떠 있는 정원 섬**: 흙 단면·지층·돌이 보이는 장난감 받침 (미니어처 디오라마 화풍)
- **잔디 9,000가닥**: 한 번에 그리는 방식(인스턴싱)으로 가닥마다 색·크기·기울기 다르게
- **흙더미**: 울퉁불퉁한 표면, 비 맞은 곳은 젖은 색·광택 + 물웅덩이 동그라미
- **식물 실제 모양**: 휘어진 잎, 튤립 꽃잎 6장, 주름진 당근(회전체), 점박이 공룡알·깨진 껍데기
- **나무 팻말 이름표**, 둥근 울타리 + 밧줄, 버섯·작은 꽃·조약돌·막대사탕 나무, 짠 바구니
- 조명·후처리: 따뜻한 낮은 햇빛 + 부드러운 그림자, 미니어처 초점, 빛 번짐, 채도·가장자리 어둡게
- 주의: 틈새 그늘(GTAO)은 이 장면에서 네모난 결함이 생겨 껐음 (실기기에서 다시 확인)
- 남은 한계: 티노·코코는 여전히 그림판 → AI 3D 모델이 생기면 교체
