# three.js(3D) 전환 검토 — 실로폰·목욕·이름표 배

작성: 2026-11-07 · 예시 이미지: `three_mockups.png` (`band_3d.webp`, `bath_3d.webp`, `boat_3d.webp`)
시제품 코드: `proto/` (three.js 0.170, 실행하려면 `npm install three@0.170.0` 후 같은 폴더에 `shared` 링크를 두고 로컬 서버로 열기)

## 결론
- **구현 가능.** 3D 소품(실로폰·욕조·배·바다)은 three.js 로 만들고, 티노·코코와 손그림 일러스트는 지금 그림을 3D 공간에 세운 판(빌보드)으로 쓰는 2.5D 방식.
- **실로폰부터 추천.** 터치(건반 톡) 하나라 구현이 가장 쉽고 3D 효과(눌리는 건반·채·그림자)가 가장 잘 보인다. 메인 5개 게임에 들어 있다.
- 목욕·배는 지금 '다른 게임'에 숨겨 둔 게임이라, 실로폰 반응을 보고 결정.

## 예시에서 보이는 것
| 게임 | 3D 로 바뀌는 점 |
|---|---|
| 가나다 실로폰 | 무지개 건반이 입체로, 채로 치면 건반이 눌리고 글자가 튀어나옴. 손그림 무대 배경 그대로 |
| 글자 목욕 | 욕조·거품·비눗방울·고무 오리가 입체. 벽 타일 그림을 거품이 덮고 있다가 문지르면 드러남 |
| 이름표 배 | 물결치는 바다 위 돛단배, 섬에서 친구를 끌어 배에 태움. 이름표는 친구 머리 위 |

## 비용·위험
| 항목 | 내용 |
|---|---|
| 용량 | three.js 본체 +약 0.68MB (압축 전송 약 171KB). 오프라인 저장 4.8MB → 약 5.5MB |
| 화풍 | 예시는 매끈한 플라스틱 느낌이라 손그림 캐릭터와 살짝 다름 → 툰 셰이딩·외곽선·종이 질감으로 맞출 수 있음 (추가 작업) |
| 기기 | WebGL 이 필요. 오래된 태블릿은 배터리·발열이 2D 보다 큼. WebGL 이 없으면 지금 2D 판으로 돌아가게 해야 함 |
| 작업량 | 실로폰 중 / 배 중~대 (3D 끌기) / 목욕 대 (3D 위 문지르기 = 그림 위에 지우개 마스크) |
| 유지보수 | 2D 엔진(tk.js)과 3D 엔진 두 가지를 같이 관리 |
| 확인 못 함 | 실제 아이패드·폰에서의 프레임·발열, 3D 화풍이 아이들에게 더 좋은지 |

## 하게 되면 순서 (제안)
1. 실로폰 3D 판을 `band3d/` 로 따로 만들어 기존 실로폰과 나란히 (비교 가능, 되돌리기 쉬움)
2. 툰 셰이딩·외곽선으로 손그림과 화풍 맞추기
3. 실기기에서 프레임·발열 확인 → 좋으면 기존 실로폰 대체, 다음 목욕/배 검토
