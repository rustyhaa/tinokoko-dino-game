# 음성 대본 (한 번에 만들어 잘라 쓰기)

기기 음성은 억양을 바꿀 수 없고 기기마다 소리가 다르다(한국어 음성이 없는 기기는 아예 무음).
그래서 **음성 사이트에서 아래 대본을 통째로 읽게 해 파일 3개**로 받으면, Claude가 쉬는 구간으로 잘라
`shared/voice/` 에 넣고 모든 기기에서 같은 목소리로 나오게 한다. 부모 녹음이 있으면 녹음이 먼저.

## 만드는 법

1. 한국어 음성 사이트를 연다 (예: Google AI Studio의 음성 생성, 네이버 클로바더빙, 타입캐스트, ElevenLabs — 말투를 글로 지시할 수 있는 곳이 억양 맞추기 쉬움).
2. 목소리: **밝고 다정한 여자(또는 남자) 선생님**, 보통보다 조금 느리게. 아래 '말투 지시'가 입력되는 곳이 있으면 붙인다.
3. 아래 대본 **A·B·C를 각각 따로** 만들어 `voice_a.mp3`, `voice_b.mp3`, `voice_c.mp3` 로 받는다 (wav·m4a 도 됨).
4. 저장소 `art/voice/` 폴더에 올린다 (브랜치 `claude/tinokoko-games-pack`, 그림 올릴 때와 같은 방법).

지킬 것
- **줄과 줄 사이를 1초 정도 쉬게** (줄바꿈마다 쉬는 사이트가 많음. 쉼이 짧으면 줄 끝에 `...` 를 붙여 다시).
- 줄 순서·개수를 바꾸지 않기 (Claude가 순서대로 이름을 붙임). 한 줄이 빠지거나 두 번 읽히면 그 파일만 다시.
- 번호는 읽히지 않게 **코드 상자 안 글자만** 붙여 넣기.

## 말투 지시 (입력 칸이 있으면)

```
3살 아이에게 그림책을 읽어 주는 다정한 유치원 선생님처럼, 밝고 또렷하게, 조금 느리게 읽어 주세요. 각 줄은 따로 떨어진 낱말이니 줄마다 1초씩 쉬고, 끝을 올리지 말고 부드럽게 내려 주세요.
```

## 게임에서 이렇게 쓰임
- 단어 읽기: B의 글자들 → A의 단어 ("나… 비… 나비!")
- 자음 맞추기: C의 이름 → A의 그 자음 단어 ("기역… 고래!")
- 발자국 길·실로폰: B의 글자
