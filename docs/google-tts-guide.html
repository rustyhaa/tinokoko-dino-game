말하는 것: Google Cloud Text-to-Speech API

글자를 사람 같은 목소리 음성 파일로 바꿔 주는 Google 서비스입니다. 키를 주시면 Claude가 128개 소리(단어·글자·자음 이름)를 한 번에 만들어 게임에 넣습니다.

어떤 서비스인지

정식 이름Cloud Text-to-Speech API (주소 texttospeech.googleapis.com)
쓸 목소리한국어 고품질 목소리 (Chirp 3 HD 또는 Neural2 계열, ko-KR) — 몇 개 샘플을 들려드리고 고르시면 됨
필요한 양약 600자 (128개 소리). 월 무료 사용량 안일 가능성이 큼
요금 (참고)무료 사용량을 넘으면 Chirp 3 HD 기준 100만 자당 약 30달러 — 요금표

해 주실 것 (약 5~10분)

  1. Google Cloud 콘솔에서 프로젝트를 하나 만듭니다 (이미 있으면 그대로).
    프로젝트 만들기
  2. 결제 계정을 연결합니다. 무료 사용량 안에서 써도 Google이 결제 수단 등록을 요구하는 것으로 알려져 있습니다 (확인 필요).
    결제 설정
  3. Cloud Text-to-Speech API를 "사용(Enable)"으로 켭니다.
    API 켜기
  4. API 키를 만들고, "키 제한"에서 Cloud Text-to-Speech API만 허용합니다.
    API 키 만들기
  5. 키는 대화창에 붙여 넣지 말고, Claude가 띄우는 보안 입력창에 넣어 주세요. ("키 받을 준비 됐어"라고 하시면 입력창을 띄웁니다.)

그다음 Claude가 하는 일

  1. 한국어 목소리 2~3개로 "나, 비. 나비!" 샘플을 만들어 들려드림
  2. 고르신 목소리로 단어 45·글자 69·자음 이름 14개를 파일로 만들어 shared/voice/에 넣음
  3. 모든 기기에서 같은 목소리로, 기기 음성 대신 재생 (부모 녹음이 있으면 녹음이 먼저)

키가 부담되면

대본 방식: docs/voice-script.md의 대본을 음성 사이트에 붙여 mp3 3개로 받아 art/voice/에 올려 주시면 Claude가 잘라서 넣습니다. 키·결제 등록이 필요 없습니다.
