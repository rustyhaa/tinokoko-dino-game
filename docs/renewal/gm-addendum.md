# 총괄 보완 지시 (master-plan.md 보다 우선)

1. **책상(글자 별자리)은 기본 잠금 유지.** 사용자가 승인한 시안대로 `cfg.desk === true` 일 때만 열린다. master-plan 의 "기본 열림(`cfg.desk !== false`)" 결정은 적용하지 않는다. 부모 화면 문구도 "켜면 열려요" 그대로.
2. **음성 파일(선택 항목) 연결 — WP-0 범위에 추가.**
   - 부모 화면에 "목소리 파일 쓰기 (시험)" 켜기/끄기 추가. 저장 키 `localStorage['tk-voicepack']` = `'1'`(켬) / 없음(끔, 기본).
   - `shared/voice/pack.json` 형식: `{"v":1,"files":{"<키>":"<파일이름.ogg>", ...}}`. 키는 낱말 그대로("티라노사우루스"), 한 글자 음절 그대로("가"), 자음 이름 그대로("기역"), 정해진 말은 `p:<이름>`("p:yay").
   - `H.pack(key)`: 켜져 있고 pack.json 을 읽었고 그 키가 있으면 `shared/voice/<파일>` 주소, 아니면 `null`. pack.json 은 켜져 있을 때만 hangul.js 가 한 번 fetch (실패하면 조용히 기기 음성). 파일·폴더가 없어도 오류가 없어야 한다.
   - 음성 파일이 켜져 있어도 `H.read(w)` 는 지금처럼 **글자 하나씩 → 낱말** 순서로 읽고 `H.hi` 강조가 따라가야 한다: 각 조각(음절·낱말)을 pack 파일로 재생하고, 그 조각의 파일이 없으면 그 조각만 기기 음성으로. 부모 녹음이 있으면 지금 동작(녹음 우선) 유지.
   - `common/build_games.py`: `shared/voice/` 폴더가 있으면 그 안의 파일을 sw.js 미리 저장 목록에 넣는다 (없으면 아무 일 없음).
3. 음성 파일 자체(`shared/voice/*.ogg`, `pack.json`, 만드는 스크립트)는 WP-0 이 끝난 뒤 별도 담당이 만든다. WP-0 은 파일 없이도 동작하게만 한다.
4. 게임 WP 는 빌드 결과(`sw.js`, `*/index.html`)를 커밋 대상에 넣지 않는다. 커밋·푸시·배포는 총괄만 한다.
